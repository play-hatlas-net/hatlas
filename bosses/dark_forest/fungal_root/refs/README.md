# Fungal Root — reference images

Drop your images in this folder, then add one line per image below.
Use only your own images, or images whose licence allows use on a paid server.
Third-party images without such a licence are **mood references only** (take ideas, never copy a design)
and belong in the git-ignored `private/` subfolder (Open Question 122).
The boss pipeline (`.claude/skills/boss-building/SKILL.md`) does not start step 1 until images are here.
